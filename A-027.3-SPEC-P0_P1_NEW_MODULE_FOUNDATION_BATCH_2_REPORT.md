## 9. L2 Foundation Standard

### Foundation Contract Pattern

Every A-027.3 module receives this standard L2 foundation structure:

```
backend/app/modules/<module_name>/
├── __init__.py
│   - MODULE_NAME
│   - UCE_ID
│   - TARGET_LEVEL = "L2"
│   - CONTRACT_VERSION = "A-027.3"
│   - FOUNDATION_STATUS = "FOUNDATION_READY"
│
└── service.py
    - validate_tenant_id(tenant_id) -> bool
      (fail-closed: None/0/-1 rejected, positive int accepted)
    
    - get_<module>_foundation_contract(tenant_id, payload=None) -> dict
      Returns deterministic dict with:
      {
        "tenant_id": tenant_id,
        "module": MODULE_NAME,
        "uce_id": UCE_ID,
        "maturity_level": "L2",
        "expansion_layer": "university_completeness",
        "service_contract_ready": True,
        "tenant_scoped": True,
        "deterministic": True,
        
        "lifecycle_statuses": [...module-specific...],
        "allowed_actions": [...module-specific...],
        "forbidden_actions": [...NO AUTO_* variants...],
        "required_evidence": [...module-specific...],
        "next_maturity_gap": "L3 deterministic logic: ...",
        
        "safety_flags": {
          "no_api_claim": True,
          "no_frontend_claim": True,
          "no_live_integration_claim": True,
          "no_provider_call": True,
          "no_kpi_claim": True,
          "no_brain_claim": True,
          "no_autonomous_execution": True,
          "no_external_side_effects": True,
          "no_l3_claim": True,
          "no_l4_claim": True,
          "no_l5_claim": True,
          "no_l6_claim": True
        }
      }
```

### Anti-Inflation Boundaries

✓ **no_api_claim:** no APIRouter, no @app decorators
✓ **no_frontend_claim:** no frontend files, no UI routes
✓ **no_provider_call:** no external service calls, deterministic only
✓ **no_kpi_claim:** no computation, no lineage
✓ **no_brain_claim:** no signal emission, no model inference
✓ **no_autonomous_execution:** all auto_* actions explicitly forbidden in contract
✓ **no_l3_claim:** next_maturity_gap explicitly references L3 as future
✓ **no_external_side_effects:** dict-only output, no state mutation
