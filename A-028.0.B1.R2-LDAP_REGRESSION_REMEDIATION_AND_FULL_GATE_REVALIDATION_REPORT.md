## 7. LDAP Root Cause Analysis

| Finding | File | Evidence | Root Cause Category | Fix Required |
|---|---|---|---|---|
| LDAP runtime default reads AUTH_LDAP_ENABLED env | backend/app/modules/integrations/service.py | get_ldap_runtime_config maps ldap.enabled to AUTH_LDAP_ENABLED default false | TEST_ENV_ENABLES_LDAP_UNINTENTIONALLY | yes |
| LDAP status computes enabled from runtime config | backend/app/modules/ldap/service.py | ldap_status uses _is_enabled(_cfg("enabled"...)) | ROUTE_STATUS_CONTRACT_CHANGED (effective via env) | no direct code change required |
| pytest bootstrap did not force LDAP disabled | backend/tests/conftest.py | no AUTH_LDAP_ENABLED override existed | TEST_ENV_ENABLES_LDAP_UNINTENTIONALLY | yes |
| failing tests require disabled-by-default without explicit config | backend/tests/test_integrations.py, backend/tests/test_ldap.py | assertions expect ldap.enabled is False | TEST_STALE_AGAINST_DOCUMENTED_BEHAVIOR | no (tests are valid) |

Root cause category:
- TEST_ENV_ENABLES_LDAP_UNINTENTIONALLY
