## 3. Issues Found and Resolved

### J-1: "renders Notification Registry page with correct heading" — ROOT CAUSE AND FIX

**Root cause**: `FIXTURE_OUTBOX_EVENTS` was a bare array `[event1, event2]` but  
`OutboxRegistry` component expects `data.items` (`OutboxEventListResponse = { items, total, page, page_size }`).  
Accessing `.length` on `undefined` threw `TypeError`, crashing Next.js with an "Application error" page — so the heading never rendered.

**Fix applied** (`frontend/e2e/smoke/rector-assignments.spec.ts`):
- Changed fixture from bare array to `{ items: [...], total: 2, page: 1, page_size: 20 }`  
- Added `level: 1` to heading selector for precision  
- Removed all diagnostic code (console listeners, page.evaluate, etc.)
