# Pilot Checklist

## Product Readiness

- [ ] suite routes reachable
- [ ] assignment flow visible
- [ ] document/decree/correspondence visible
- [ ] Control Tower visible
- [ ] role-based access verified
- [ ] evidence/report flow verified
- [ ] SLA/outbox visibility verified
- [ ] audit/archive visible
- [ ] limitations visible

## Technical Readiness

- [ ] Docker runtime reproducible
- [ ] Nginx route smoke PASS
- [ ] backend smoke PASS
- [ ] frontend type-check PASS
- [ ] frontend tests PASS
- [ ] Playwright smoke PASS
- [ ] backup/restore dry-run proof
- [ ] logs/request_id visible
- [ ] tenant isolation smoke
- [ ] RBAC denial smoke

## Operational Readiness

- [ ] pilot owner assigned
- [ ] pilot users defined as placeholders only
- [ ] training guide drafted
- [ ] support channel defined
- [ ] issue triage workflow defined
- [ ] rollback plan documented
- [ ] acceptance criteria approved

## Governance Readiness

- [ ] no real personal data
- [ ] no live email/SMS
- [ ] no provider integration claim
- [ ] no auto-signature
- [ ] no auto-approval
- [ ] no autonomous decision
- [ ] no production-ready claim
