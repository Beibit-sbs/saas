# Executive User Guide

## Purpose

Help executive users review the suite as an oversight tool.

## Intended Users

- Rector / President
- Vice Rector

## What The Role Can Do

- review Control Tower
- review assignment status and linked governance context
- review SLA and overdue visibility
- review audit/archive summary views

## What The Role Cannot Do

- no auto-signature
- no autonomous decision
- no fake KPI override
- no production-ready claim

## Basic Workflow

1. Open Control Tower.
2. Review assignment and risk visibility.
3. Open linked assignment or governance detail.
4. Review audit and archive evidence.

## Limitations

- no sales-ready claim
- no L5/L6 claim
- no provider integration
- no real personal data

## Support Notes

- escalate access issues through the pilot support path
- record missing routes as pilot gaps, not runtime facts

## Pilot Feedback Questions

- Which visibility views are most useful?
- Which labels need clearer explanation?
- What additional governance drilldowns are needed?
