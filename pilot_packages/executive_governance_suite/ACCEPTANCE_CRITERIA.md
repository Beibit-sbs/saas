# Acceptance Criteria

## Functional Acceptance

- Rector can view Control Tower.
- Assignment lifecycle can be demonstrated.
- Report/evidence flow can be demonstrated.
- Document/decree/correspondence lifecycle can be demonstrated.
- SLA/overdue visibility can be demonstrated.
- Audit/history visibility can be demonstrated.

## Quality Acceptance

- backend smoke PASS
- frontend type-check PASS
- frontend targeted tests PASS
- Playwright smoke PASS
- no fake KPI
- no mutation in read-only surfaces
- no provider dispatch
- no production-ready claim

## Governance Acceptance

- role matrix approved
- pilot limitations accepted
- data privacy constraints documented
- no real personal data used
- rollback plan available

## Evidence Acceptance

- screenshots captured
- E2E logs archived
- test counts recorded
- known limitations listed
- sign-off template prepared
