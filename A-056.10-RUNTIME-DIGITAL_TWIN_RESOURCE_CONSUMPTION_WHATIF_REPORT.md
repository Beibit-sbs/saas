# A-056.10 Runtime - Digital Twin Resource-Consumption What-If Report

## Scope

Second Digital Twin domain (NATIONAL_OS_TREE #21 "resource consumption
intelligence"): a deterministic days-of-stock what-if + shortage early-warning
for consumables / utilities. Built with the A-056.R1 hardening discipline baked
in from the start (finite-input validation -> clean 400, fail-closed, no fake
metrics, no autonomy).

## Result

- Routes (route count 7 -> 9; reuse `digital_twin.simulate.run`):
  - `POST /api/admin/digital-twin/simulate/resource`
  - `POST /api/admin/digital-twin/early-warning/resource`
- Service:
  - `simulate_resource`: `projected_days_remaining = round(current_stock / daily_consumption, 2)`
    (None + incomplete_data when consumption is 0); `reorder_needed` when days <= lead_time + safety_buffer;
    risks `stockout_before_lead_time` (days < lead_time) / `reorder_point_reached`.
  - `resource_early_warning`: high (stockout) / medium (reorder) warning with a recommended human
    action (`escalate_to_procurement_reorder` / `raise_reorder_request`).
  - `current_stock` and `daily_consumption` validated finite via `_validate_finite` -> non-finite
    input fails closed with 400 (no 500, no inf-in-422).
  - Evidence tagged: current_stock->asset_inventory, daily_consumption->operations.
- Frontend: read-only "Resource-consumption what-if" section on /console/digital-twin.

## Safety / Honesty

- Deterministic; missing consumption -> incomplete_data (never guessed).
- Read-only; recommends a human action, executes nothing; "no supplier order without human approval".
- `fake_metrics=false`, `human_review_required=true`; viewer denied (403).
