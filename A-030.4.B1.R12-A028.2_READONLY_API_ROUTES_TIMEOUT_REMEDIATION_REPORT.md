## 4. Root Cause Analysis

### Prior Behavior
- File: backend/tests/test_a0282_expansion_l4_readonly_api_routes.py
- Problem: test_client fixture scoped to function (default)
- Effect: Each test using `test_client` parameter created new TestClient(app)
- Cost: 6 route configs × multiple parametrized test variants = many fixture instantiations
- Result: ~30 minutes for 122 tests

### Test Structure
```python
# Before (expensive):
@pytest.fixture
def test_client() -> TestClient:
    return TestClient(app)  # Creates NEW app init per test

# After (efficient):
@pytest.fixture(scope="module")
def test_client() -> TestClient:
    return TestClient(app)  # Single app init per module
```

### Why This Works
- TestClient(app) initializes the entire FastAPI application
- With module scope, app is initialized once at module start and reused
- All 122 tests in the module reuse the same client instance
- Reduces app initialization overhead by 99%
