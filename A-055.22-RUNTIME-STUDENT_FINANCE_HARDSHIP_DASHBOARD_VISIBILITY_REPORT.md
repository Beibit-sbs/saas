## Scope

Expose finance-origin hardship support visibility in Student Services Support dashboard:

```text
finance handoff hardship records -> dashboard summary -> reviewer queue and evidence gap counts
```

## Result

Extended existing dashboard endpoint without adding new routes or permissions:

- Backend endpoint remains:
  - `GET /api/admin/student-services/dashboard/summary`
- Backend response now includes:
  - `finance_hardship_handoff_visibility`
  - `total`
  - `review_queue_count`
  - `missing_evidence_count`
  - `readiness_counts`
  - finance handoff source metadata and safety flags
- Backend repository now counts hardship readiness records by `metadata_json.source_flow`.
- Frontend dashboard now renders a dedicated `Finance hardship handoff visibility` block.
- Frontend keeps a link back to Student Finance Bridge.

It does not approve aid, reject aid, cancel debt, mutate billing balances, execute payments, rank students by hidden score, or call external providers.

- `noAutomaticAidDecision=true`
- `noBillingBalanceMutation=true`
- `humanReviewRequired=true`
- `fake_metrics=false`
- `provider_live_enabled=false`
- `autonomous_decision_enabled=false`
- `hidden_score_present=false`
