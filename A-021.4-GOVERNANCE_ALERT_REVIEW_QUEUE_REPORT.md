## 7. Alert Derivation Rules

Deterministic mapping from existing KPI evidence only:
- If no domain evidence in current tenant snapshot -> `severity=unavailable`, `reviewStatus=unavailable`.
- Else if any critical metric > 0 -> `severity=critical`.
- Else if any high metric > 0 -> `severity=high`.
- Else if review/medium metrics > 0 -> `severity=medium`.
- Else -> `severity=low`.

Review status mapping:
- `review_required` when review/critical/high signals exist.
- `watch` when only watch metrics are positive.
- `resolved` only when resolved metrics are supported and positive with no active review/high signals.
- `evidence_only` when evidence exists but no elevated review signal.
- `unavailable` for missing domain evidence.
