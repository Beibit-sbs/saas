## Root Cause Analysis

### Issue 1: Service Dependency Deadlock (Primary Suspect)
**Problem:** Backend-tests service `depends_on` configuration requires:
```yaml
depends_on:
  pgbouncer:
    condition: service_healthy
  redis:
    condition: service_healthy
  backend:
    condition: service_healthy
```

**When running:** `docker compose run --no-deps --rm backend-tests ...`

The `--no-deps` flag should skip dependencies, but the compose file's dependency definition may still be causing issues with the command execution path.

### Issue 2: Docker-Compose Default Command
**Problem:** Docker-compose.yml line 151-153:
```yaml
command:
  - sh
  - -lc
  - pytest -q
```

This hardcoded default command may not be properly overridden by `docker compose run` arguments. The container is created but the command execution chain is broken.

### Issue 3: Environment Escalation
**Problem:** After Step 5 attempted, subsequent `docker compose ps` commands also hung:
```bash
$ docker compose ps
[... hangs indefinitely ...]
^C (exit 130)
```

This indicates **docker-compose process itself has become unresponsive**, not just the backend-tests container.
