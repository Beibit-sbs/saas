## 10. Guard Contract

- future guard functions:
  - assertTrustedControlTowerResponse(response)
  - isTrustedControlTowerResponse(response)
  - assertTrustedMetric(metric)
  - isMetricUnavailable(metric)
  - isMetricStale(metric)
  - formatMetricValue(metric)
  - getMetricDisplayState(metric)
- guard rules:
  - if fake_metrics !== false, block widgets
  - if data_source !== computed_from_governance_workflows, block widgets
  - if metric.fake_metrics !== false, block metric
  - if metric.value is null or undefined, show Unavailable
  - if response.incomplete_data === true, show incomplete data notice
  - if metric.runtime_status is FOUNDATION_CONTRACT_ONLY, show foundation-only badge
  - if metric.readiness is FUTURE_CONTRACT, show deferred badge
  - if stale, show stale warning
  - never coerce null to 0
  - never show trend unless backend returns a real trend contract
- required labels:
  - Computed from governance workflows
  - Incomplete data
  - Unavailable
  - Future contract
  - Foundation-only metric
  - Evidence-linked metric
  - No automated decision is made by this dashboard

- null or undefined: render Unavailable
- incomplete_data=True: render warning notice
- FUTURE_CONTRACT: render Future contract

- no evidence links: render Evidence link unavailable
