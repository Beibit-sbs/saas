## Risk Heatmap Model

- Input: existing `data.cards` payload from `useRectorDashboard(tenantId)`
- Domain derivation: each domain maps to known KPI metric keys
- Risk label derivation:
  - `unavailable`: no matching evidence in tenant snapshot
  - `critical`: any domain critical KPI value > 0
  - `risk`: any domain risk KPI value > 0
  - `watch`: any domain watch/review KPI value > 0
  - `healthy`: evidence exists and no risk/watch/critical signal triggered
- Output:
  - Domain title
  - Risk label
  - Source domains
  - Evidence items with current values
  - Data quality note for optional/missing evidence
