# A-055.17 Runtime - Student Graduated Status Guard And Alumni Branch Readiness Report

## Scope

Continue the SaaS tenant runtime tree after graduation readiness review:

```text
superadmin -> tenant -> tenant admin -> org/program/course -> student
-> program binding -> term/section/enrollment -> lesson/attendance
-> grading scale/grade -> transcript/GPA -> degree progress
-> graduation readiness review -> graduated status -> alumni branch
```

## Result

The backend already had the critical fail-closed guards:

- `students` status transition to `graduated` rechecks official degree-progress eligibility.
- `alumni` record creation requires the student profile to already be `graduated`.

This slice exposed those guards in the admin runtime shell:

- Added frontend student status transition API and hook for `PATCH /api/admin/students/{id}/status`.
- Added a degree-progress action to mark an eligible student as `graduated`.
- The graduation action uses the current student profile `version` for optimistic locking.
- The graduation action is disabled unless official eligibility is true and the profile is not already graduated.
- Added a graduated-student selector to the alumni page while keeping a manual ID fallback.
