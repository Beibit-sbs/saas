# A-039.2-SPEC - HR Staff Governance Suite Backend Domain / DB / API Contract Report

## 1. Executive Summary

A-039.2-SPEC defines the backend domain, database, API, permission model, schema contract, repository contract, service contract, evidence and audit contract, dashboard contract, bridge contract, Brain readiness boundaries, provider readiness boundaries, tenant and RBAC safeguards, and targeted backend test plan for the future HR / Staff Governance Suite backend foundation. This action is backend contract specification only and docs only. No backend runtime, migrations, models, schemas, repositories, services, routers, tests, frontend runtime, Playwright specs, provider integrations, or real HR data were created or changed in this action.

The backend strategy remains one controlled module at `backend/app/modules/hr_staff_governance/`, not one package per capability row. The contract uses `hr_` database tables, tenant fail-closed behavior, explicit RBAC permissions, metadata-and-evidence-only safety defaults, append-only audit and status history, read-only-first bridge records, dashboard responses with `fake_metrics=false`, provider readiness profiles with live integration disabled, and anti-fake boundaries that forbid automatic hiring, firing, leave approval, disciplinary outcome automation, payroll execution, autonomous access revocation, hidden scores, fake HR or payroll data, provider live sync, and external DB synchronization.
