## Backend Result

`POST /platform/tenants` now supports two compatible modes:

1. Legacy invite mode:
   - input: `tenant_name`, `admin_email`
   - result: tenant defaults + invite token

2. Direct tenant admin mode:
   - input: `tenant_name`, `admin_email`, `admin_login`, `admin_password`
   - result: tenant defaults + first local tenant admin user
   - no invite token is returned

The direct mode creates the local user inside the created tenant with role `admin`, syncs trusted RBAC roles, and rolls back the tenant/user if admin creation fails.

## Frontend Result

- plan code

The existing tenant list remains on the same screen.
