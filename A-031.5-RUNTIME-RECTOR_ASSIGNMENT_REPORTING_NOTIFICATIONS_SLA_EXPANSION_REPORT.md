## New Database Tables

### `rector_assignment_outbox_events` (table 11)
Tracks notification events queued from assignment lifecycle transitions.

| Column | Type | Notes |
|---|---|---|
| id | BigInteger PK | auto |
| tenant_id | BigInteger | NOT NULL, indexed |
| assignment_id | BigInteger FK | rector_assignments.id |
| event_type | String | OutboxEventType enum values |
| channel | String | OutboxChannel enum values |
| status | String | PENDING/READY/CANCELLED |
| payload | JSONB | event-specific data |
| queued_at | DateTime | timestamp |
| ready_at | DateTime | nullable |
| cancelled_at | DateTime | nullable |
| created_by_id | BigInteger | actor who triggered event |
| audit_event_id | BigInteger | FK rector_assignment_audit_events.id |

### `rector_assignment_sla_policies` (table 12)
Configurable SLA thresholds by priority level.

| Column | Type | Notes |
|---|---|---|
| id | BigInteger PK | auto |
| tenant_id | BigInteger | NOT NULL, indexed |
| name | String | policy name |
| priority | String | SlaPolicyPriority enum values |
| deadline_days | Integer | days from assignment to deadline |
| warning_days | Integer | days before deadline for warning |
| is_active | Boolean | soft-delete flag |
| created_by_id | BigInteger | actor |
| archived_at | DateTime | nullable |

### `rector_assignment_escalation_policies` (table 13)
Escalation rules for overdue assignments.

| Column | Type | Notes |
|---|---|---|
| id | BigInteger PK | auto |
| tenant_id | BigInteger | NOT NULL, indexed |
| name | String | policy name |
| target_role | String | EscalationTargetRole enum values |
| trigger_after_days | Integer | days overdue before escalation |
| require_manual_confirmation | Boolean | default True |
| is_active | Boolean | soft-delete flag |
| created_by_id | BigInteger | actor |
| archived_at | DateTime | nullable |

## Notable Implementation Notes

1. **Route ordering**: Fixed-path routes (`/outbox`, `/sla-policies`, `/escalation-policies`) MUST be registered before `/{assignment_id}` in FastAPI — learned from Gate 2 failures where `/outbox` was matching as `assignment_id="outbox"`.

2. **int(actor) in tests**: Routes that call `int(actor)` (create/update/archive) require numeric user_id in auth headers. Test headers using "owner@example.com" as actor will fail with 400. Solution: create `_auth_headers("1", ...)` with numeric user_id for those routes.

3. **RBAC must be updated in rbac/service.py**: New permissions in `permissions.py` must also be added to both role definition frozensets in `backend/app/modules/rbac/service.py` (both "owner/superadmin" and "admin" role blocks).
