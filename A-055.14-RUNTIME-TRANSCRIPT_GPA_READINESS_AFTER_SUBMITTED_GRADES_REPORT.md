## Result

The transcript frontend now matches the official backend contract:

```text
student_profile_id
total_credits
gpa
items[]
  -> enrollment_id
  -> term
  -> course
  -> credits
  -> grade_code
  -> grade_points
```

Transcript page now:

- displays GPA from the backend transcript response
- displays canonical transcript items instead of legacy `entries`
- shows course, term, credits, grade code, and grade points
- uses student lookup for readable student heading
- handles transcript snapshot response wrapper correctly

The transcript lookup page now:

- loads active students
- lets tenant admin select a student instead of typing an unknown id
- keeps manual student profile id fallback

Backend transcript read now auto-heals transcript records when current enrollment grade fields differ from stored transcript records:

```text
grade submit/change
  -> enrollment.grade_code / enrollment.grade_points
  -> GET transcript detects missing/mismatched transcript record
  -> regenerate transcript records
  -> return updated GPA/items
```
