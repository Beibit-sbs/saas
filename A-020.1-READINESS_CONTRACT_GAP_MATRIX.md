## Readiness Contract Core Fields

Fields to standardize/confirm across all modules:

### Who Needs the Room
- `tenant_id` ✓ (present, validated)
- `section_id` ✓ (present, optional in some events)
- `course_id` ✓ (present)
- `group_id` ✗ (not used, optional for future)
- `teacher_id` / `instructor_id` ✓ (aliased in context source)

### What is Required
- `required_capacity` ✓ (present in room_booking, context source)
- `students_count` ✓ (aliased as enrolled_count)
- `required_room_type` ✗ (missing, optional add)
- `required_computers` ✗ (missing, optional add)
- `equipment_required` ✗ (missing, optional add)

### What Room Provides
- `room_id` ✓ (present)
- `room_capacity` ✓ (present)
- `room_type` ✗ (in scheduling models but not surface via context source)
- `computers_count` ✗ (missing)
- `equipment_available` ✗ (missing)

### When
- `day_of_week` ✓ (in scheduling)
- `time_slot_id` ✓ (in scheduling)
- `start_time`, `end_time` ✓ (in room_booking)

### Evidence
- `capacity_mismatch` ✓ (emitted as event)
- `room_conflict` ✓ (emitted as event)
- `room_allocation_required` ✓ (boolean in context source)
- `reason` ✗ (missing explicit reason string)
- `source_entity_type` ✗ (missing)
- `source_entity_id` ✗ (missing)
