# A-056.9 Runtime - Digital Twin Decision Log Read-Back Report

## Scope

Complete the decision loop's read side: an executive decision log that reads back
the recorded scenario decisions (A-056.8) from the audit trail. Read-only,
tenant-scoped.

## Result

- Backend route: `GET /api/admin/digital-twin/scenarios/decisions` (reuses
  `digital_twin.decision.record`; route count 6→7, permission unchanged).
- Service `list_scenario_decisions`: queries the audit trail via
  `audit.service.list_admin_actions(action="digital_twin.scenario_decision_recorded",
  tenant_id=...)` and maps each event to a log item (reviewer/actor, scenario_name,
  decision, rationale, correlation_id, timestamp).
- The audit trail is the system of record — no separate store, consistent with A-056.8.
- Frontend: read-only "Executive decision log" section on /console/digital-twin.

## Safety / Honesty

- Read-only; tenant-scoped (fail-closed); `no_autonomous_execution=true`.
- Reuses the existing audit infrastructure; nothing is fabricated — empty trail → empty log.
- Viewer without the permission denied (403).
