# A-055.13 Runtime Grading Scale Selector Shell Before Transcript GPA Report

Date: 2026-06-18

## Scope

Thirteenth correction slice after grade entry:

```text
grade entry
  -> grading scale catalog
  -> grading scale selector
  -> transcript/GPA readiness
```

The goal of this slice was to remove the need for tenant admin operators to type `grading_scale_id` manually when submitting or changing grades.

## Result

Backend now exposes tenant grading scale catalog endpoints:

```text
GET  /api/admin/grades/scales
POST /api/admin/grades/scales
```

The scale model includes:

```text
scale
  -> name
  -> description
  -> active flag
  -> grade code items
     -> grade_code
     -> grade_points
     -> min_percentage
     -> max_percentage
```

Grades page now:

- loads active grading scales
- lets tenant admin create a standard A-F / 4.0 scale
- uses grading scale selectors for grade submit and grade change
- keeps raw id fallback only when no scales exist yet
- continues the enrollment-backed grade flow from A-055.12

Updated runtime chain:

```text
tenant admin
  -> create term
  -> create section
  -> enroll student
  -> create lesson
  -> mark attendance
  -> create/select grading scale
  -> submit grade
```

## Current Limits

This slice creates a compact scale shell inside Grades page. A later dedicated Grade Settings page can add:

- deactivate/edit scale
- add/remove individual grade code rows
- institution policy presets
- transcript policy mapping
