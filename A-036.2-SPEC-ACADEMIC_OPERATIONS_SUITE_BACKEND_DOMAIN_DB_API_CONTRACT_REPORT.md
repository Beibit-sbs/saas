### Curriculum / Course Catalog

1. `ao_curricula`
   - purpose: top-level curriculum metadata registry
   - key columns: `id`, `tenant_id`, `curriculum_code`, `program_code`, `title`, `status`, `review_notes_json`, `limitations_json`, `human_review_required`, `archived_at`, `created_at`, `updated_at`
   - foreign keys: none direct; parent for curriculum versions, mappings, and status history
   - status fields: `status: CurriculumStatus`, `human_review_required=true`
   - archive strategy: soft archive via `status=ARCHIVED` and `archived_at`; no hard delete
   - audit requirement: create/update/submit/review/approve/archive emit audit events and status-history rows
