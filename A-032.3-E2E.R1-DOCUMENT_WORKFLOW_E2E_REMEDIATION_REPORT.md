## 5. TypeScript Root Cause

- shared client contract: apiGet accepts Record<string, string | number | boolean | undefined> for query params
- failing callers: listDocuments, listDecrees, listCorrespondence in frontend/modules/document-workflow/api.ts
- root cause: DocumentListFilters, DecreeListFilters, and CorrespondenceListFilters are typed interfaces without a string index signature, so TypeScript rejected passing them directly to apiGet even though their runtime shape was valid

## 6. Remediation Applied

- file changed: frontend/modules/document-workflow/api.ts
- remediation: added a small local query filter normalizer and passed normalized filter records into apiGet
- behavior preserved:
  - skip undefined, null, and empty-string query values
  - preserve BFF routing through shared apiGet/apiPost/apiPatch
  - no backend host hardcoding
  - no feature expansion
