## 1. Executive Summary

A-022.9 remediated the long-standing `University Core Table Coverage` smoke blocker by correcting the validation policy to match the already-established A-011.5 runtime contract.

Root cause:
- `validate_entity_tables_impl()` treated every `ENTITY_CONFIGS` table as DB-required.
- The repository already formalized a narrower policy: only 15 A-011.5 tables are DB-required; the remaining 66 missing tables are planned/test-only fallback tables and intentionally use in-memory fallback.

Chosen remediation path:
- **Path C — classification-aware gate correction**
- No schema expansion for the 66 deferred tables.
- No silent hiding of fallback debt: the 66 tables remain explicitly reported as `missing_fallback` / fallback-allowed.

Result:
- University Core coverage no longer blocks smoke for the wrong reason.
- The previous A-022 smoke blocker is removed.
- The current smoke failure moved forward to an unrelated frontend billing Playwright slice.

## 2. Root Cause and Source of Truth

Exact failing path before remediation:
- `scripts/platform_smoke_check.sh` called `validate_entity_tables_impl()`.
- `backend/app/modules/university_core/entity_impl.py` returned every missing `ENTITY_CONFIGS` table in `missing`.
- Smoke failed on 66 fallback-allowed missing tables.

Authoritative source-of-truth already in repo before this change:
- `backend/alembic/versions/yp24qr56st78_a011_5_create_15_active_fallback_tables.py`
- `backend/tests/test_university_core_entity_tables_exist.py`
- `A-011.4-UNIVERSITY_CORE-FALLBACK-CLASSIFICATION-REPORT.md`

Policy already encoded there:
- 15 tables are DB-required (`ACTIVE_PRODUCTION_REQUIRED` or `ACTIVE_INTERNAL_REQUIRED`).
- 63 tables are `PLANNED_NOT_ACTIVE`.
- 3 tables are `TEST_ONLY_OR_STUB`.
- Those 66 deferred tables are intentionally allowed to fall back to in-memory storage.

## 3. Implementation

Files changed:
- `backend/app/modules/university_core/shared.py`
- `backend/app/modules/university_core/entity_impl.py`
- `backend/tests/test_university_core_entity_tables_exist.py`

What changed:
- Added authoritative `REQUIRED_DB_TABLES` constant for the 15 A-011.5 DB-backed tables.
- Added `TEST_ONLY_DB_TABLES` and `ALLOWED_FALLBACK_TABLES` constants for explicit classification.
- Changed `validate_entity_tables_impl()` so that:
  - `missing` now means missing **required** DB-backed tables only.
  - `present` now tracks present **required** DB-backed tables.
  - `missing_fallback` reports deferred fallback-allowed tables still absent from DB.
  - `present_fallback` reports fallback-allowed tables that do exist.
- Preserved visibility of deferred table debt via warning logs and structured return fields.
- Updated the regression test to assert the new contract directly:
  - required missing tables must be empty
  - fallback-missing count remains 66
