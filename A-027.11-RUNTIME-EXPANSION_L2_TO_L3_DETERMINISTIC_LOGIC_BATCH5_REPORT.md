## 9. Evidence Completeness Logic

Deterministic calculation:
- missing_evidence = required_evidence - present_evidence
- evidence_completeness = int(((required - missing) / required) * 100)

Readiness mapping:
- all required present -> READY_FOR_REVIEW
- no present evidence -> BLOCKED_MISSING_EVIDENCE
- completeness below threshold -> INCOMPLETE_EVIDENCE
- otherwise -> PARTIAL_EVIDENCE

Risk mapping:
- READY_FOR_REVIEW -> LOW
- PARTIAL_EVIDENCE -> MEDIUM
- INCOMPLETE_EVIDENCE -> HIGH
- BLOCKED_MISSING_EVIDENCE -> BLOCKED

Recommended next step mapping:
- READY_FOR_REVIEW -> READY_FOR_HUMAN_REVIEW
- PARTIAL_EVIDENCE/INCOMPLETE_EVIDENCE -> REQUEST_MISSING_EVIDENCE
- BLOCKED_MISSING_EVIDENCE -> BLOCK_UNTIL_REQUIRED_EVIDENCE_PRESENT
