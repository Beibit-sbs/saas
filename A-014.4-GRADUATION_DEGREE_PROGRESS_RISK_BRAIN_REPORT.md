# A-014.4 — Graduation / Degree Progress Risk Brain: Evidence Report

**Status:** CLOSED — PASS  
**Completed:** 2026-05-05  
**Constraint mode:** additive-only, reuse-first, no migrations, no new public endpoints

---

## 1. Objective

Close the graduation / degree progress Brain loop so that:
- `degree_progress.graduation_risk.detected` is accepted by Brain Core instead of being ignored.
- High/medium graduation risk routes to already-supported intervention/advisor actions rather than unsupported graduation-specific action names.
- `student_profile_id` emitted by degree progress is normalized into canonical Brain signal fields so intervention creation, origin evidence, and tenant isolation work end-to-end.
- Duplicate graduation-risk signals deduplicate safely even when DB persistence is unavailable in unit/container test paths.
- Transcript inconsistency signals can reuse the same supported path when they explicitly carry graduation-risk context.

---

## 2. Change Summary

### `backend/app/modules/brain_core/constants.py`
- Added `DEGREE_PROGRESS_EVENT_TYPES` with `degree_progress.graduation_risk.detected`.
- Included degree progress events in `SUPPORTED_SIGNAL_EVENT_TYPES`.

### `backend/app/modules/brain_core/registry.py`
- Registered `degree_progress.graduation_risk.detected` in `SignalRegistry`.
- Added `graduation_degree_progress_risk` decision scenario.
- Mapped the scenario only to already-supported actions:
  - `create_intervention_case`
  - `notify_advisor`

### `backend/app/modules/brain_core/reasoning/rules_engine.py`
- Replaced unsupported graduation action names:
  - removed `create_graduation_audit_case`
  - removed `notify_academic_advisor`
  - removed `escalate_to_dean`
- High/medium graduation paths now emit `decision_type = "intervention"` with supported actions.
- Low graduation risk remains non-actionable (`recommended_actions = []`).

### `backend/app/modules/brain_core/service.py`
- Added `_normalize_degree_progress_signal()` to fail closed on missing student context and normalize:
  - `student_profile_id -> student_id`
  - default `source_entity_type = student_graduation_progress`
  - default `source_entity_id = student_id`
- Added `_resolve_decision_scenario()` so transcript inconsistency with explicit graduation context can reuse the graduation scenario.
- Added in-memory dedup cache fallback so duplicate detection works without DB persistence.
- Fixed dedup key derivation to fall back to `payload.source_entity_*`, preventing unrelated regressions in existing Brain Core tests.
- Added backward-compatible `record_dispatch_outcome` shim for legacy programs/courses callers.
- Added module-level `record_dispatch_outcome()` proxy for older `from ... import service as brain_core_service` patterns.

### `backend/app/modules/brain_core/classifiers/risk_classifier.py`
- Extended `transcripts.inconsistency.detected` classification so explicit `graduation_risk_detected=True` can route into `graduation_risk_high|medium`.

### `backend/tests/test_graduation_degree_progress_risk_brain_a014_4.py`
- New focused suite covering:
  - registry/scenario wiring
  - intervention dispatch + origin evidence preservation
  - idempotent deduplication
  - fail-closed missing-student behavior
  - tenant isolation
  - low-risk no-op path
  - transcript-context reuse path
