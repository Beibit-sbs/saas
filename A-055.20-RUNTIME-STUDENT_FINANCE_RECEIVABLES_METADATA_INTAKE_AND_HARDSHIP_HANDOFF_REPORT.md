# A-055.20 Runtime - Student Finance Receivables Metadata Intake And Hardship Handoff Report

## Scope

Continue the student finance bridge after A-055.19:

```text
student finance bridge -> receivables metadata intake -> hardship human-review handoff
```

## Result

Added a metadata-only receivables intake path inside Finance / Procurement / Asset:

- Backend route:
  - `POST /api/admin/finance-procurement-asset/receivables/metadata`
- Backend permission:
  - `finance_procurement_asset.receivables.metadata`
- Backend service:
  - `create_receivables_metadata(...)`
  - writes `fpa_receivables_metadata`
  - keeps `payment_execution_enabled=false`
  - keeps `fake_finance_data=false`
  - records audit metadata through the existing FPA metadata path.
- Frontend API:
  - `createFpaReceivablesMetadata(...)`
- Student finance bridge UI:
  - shows receivables intake contract fields,
  - shows hardship handoff link to `/console/student-services-support/hardship`,
  - keeps the handoff human-review-only.

## Safety Boundaries

This slice does not create real charges, execute payments, cancel debt, approve aid, or mutate ERP/bank state.

Explicitly preserved:

- `tuitionChargeCreation=false`
- `paymentExecutionEnabled=false`
- `liveErpSync=false`
- no automatic hardship approval,
- no automatic aid decision,
- no billing balance mutation,
- no payment execution.
