**Diagnosis: --network + --env-file hang pattern**

R13 identified that the `--network ai_default --env-file infra/.env` combination causes test hangs because `infra/.env` contains:
- `DATABASE_URL=postgresql://app:app@db:5432/app` — live DB connection
- `AUTH_LDAP_ENABLED=true` — live LDAP connection

When tests are run in Docker with these env vars, the app tries to connect to real DB/LDAP instead of using in-memory fallbacks. The conftest.py is designed for in-memory isolation (it explicitly avoids setting DATABASE_URL). Running with --env-file overrides this design.

**R12 and prior valid runs all used direct Docker mode without --network/--env-file**, which correctly activates conftest's in-memory isolation mode.
