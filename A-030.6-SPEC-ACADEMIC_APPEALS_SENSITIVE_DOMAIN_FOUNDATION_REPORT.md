## 13. Expected Tenant Validation

The service function must use a strict `validate_tenant_id` function that is **fail-closed** — it must reject all invalid inputs with `ValueError`.

**Required rejections** (must raise `ValueError`):
| Input | Reason |
|-------|--------|
| `None` | Not an integer |
| `0` | Zero is not a valid tenant |
| `-1` (any negative) | Negative integer not valid |
| `"1"` (string) | String not accepted |
| `True` (bool) | bool is subclass of int — must be explicitly rejected |
| `False` (bool) | bool is subclass of int — must be explicitly rejected |
| `1.5` (float) | Float not accepted |

**Required acceptance**:
| Input | Result |
|-------|--------|
| `1` (positive int) | Accepted, returns dict |
| `100` (positive int) | Accepted, returns dict |
| `999` (positive int) | Accepted, returns dict |

**Critical**: Must check `isinstance(tenant_id, bool)` **before** `isinstance(tenant_id, int)` because `bool` is a subclass of `int` in Python — `isinstance(True, int)` returns `True`.
