# A-055.11 Runtime Readable Student Identity Labels For Attendance Report

Date: 2026-06-18

## Scope

Eleventh correction slice after enrolled student attendance selector:

```text
student profile id
  -> student number/name
  -> attendance selector label
```

The goal of this slice was to make attendance selection readable for tenant admin operators.

## Changed Files

Frontend:

- `frontend/app/(admin)/console/scheduling/page.tsx`
- `frontend/__tests__/admin/SchedulingPage.test.tsx`

## Result

Scheduling page now:

- loads active tenant students alongside section enrollments
- builds a student lookup by profile id
- labels attendance choices with student number and name when available
- keeps profile id fallback when the student record is missing

Readable selector label:

```text
S-1001 / Aida Karim / Enrollment #9001
```

Fallback selector label:

```text
Student #1001 / Enrollment #9001
```

This improves the current attendance flow:

```text
select section
  -> select/create lesson
  -> select enrolled student by readable identity
  -> mark attendance
```

## Test Coverage Added

`SchedulingPage.test.tsx` now verifies that attendance student options use student number and name when the tenant student record is available.
