- `formula: string`
- `filters: list[string] | object`
- `tenant_scope: required`
- `permission_required: string`
- `freshness_timestamp_field: string`
- `staleness_threshold_minutes: int`
- `evidence_link_type: string`
- `evidence_reference_fields: list[string]`
- `data_source: string`
- `fake_metrics: bool`
- `incomplete_data: bool`
- `limitations: list[string]`
- `failure_mode: string`
- `ui_display_rule: string`

Required invariants:
- `fake_metrics` must always be `False`
- `data_source` must always be `computed_from_governance_workflows`

Required failure behavior:
- if source missing: `incomplete_data=True`
- if permission missing: `metric_hidden` or `permission_denied`
- if stale: show stale warning
- if unavailable: show unavailable
- never invent zero
- never fake trend

Registry-wide defaults:
- `tenant_scope = tenant_id scoped`
- `failure_mode = unavailable_or_incomplete`
- `ui_display_rule = show value only when source valid and permission granted`

Source field discipline:
- use implemented field names when confirmed from source modules
- if an exact runtime field is still uncertain, mark it `SOURCE_FIELD_TO_VERIFY_IN_RUNTIME_SPEC`
