## 5. Test Authoring Notes

### Initial 3/6 failures (corrected in same session — no production code changes)

The initial test file contained three authoring errors:

1. **`academic.interventions_created`** — not a valid event type in `VALID_EVENT_TYPES`; corrected to `interventions.case.created`
2. **`academic.thesis_delay.detected`** — not registered in `SignalRegistry`; corrected to `thesis.status_changed`
3. **`academic.graduation_risk.detected`** — not registered in `SignalRegistry`; corrected to `degree_progress.graduation_risk.detected`

No production code was changed. All fixes were in the test file only.
