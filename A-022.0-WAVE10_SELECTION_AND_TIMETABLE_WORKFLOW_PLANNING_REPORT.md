## 9. Human-Approved Timetable Safety Model

### Automation Levels (1–5)

| Level | Name | Definition | A-022 Status |
|-------|------|-----------|--------------|
| **1** | **Detect** | Passive observation; alert only | Core (A-020.3 foundation) |
| **2** | **Recommend** | Suggest rooms; no commitment | Core (A-020.5 foundation) |
| **3** | **Simulate** | Read-only preview; no mutation | **DEFAULT TARGET** (A-022.2) |
| **4** | **Human-Approved Proposal** | Reviewer approves/rejects with audit | Extended (A-022.1, A-022.4 optional) |
| **5** | **Controlled Apply** | Execute change; rollback-enabled | **EXPLICITLY DEFERRED** (post-A-022) |

### A-022 Default Target: **Level 3 (Simulate)**

```
Timetable Change Workflow (A-022 Default):

User Workflow:
  1. Admin selects section/course → detect conflicts (Level 1)
  2. System recommends candidate rooms (Level 2, from A-020.5)
  3. Admin selects recommendation → simulate change (Level 3)
  4. System shows conflict delta: before/after, severity, affected entities
  5. Admin reviews simulation result
  6. STOP: No auto-apply
  
Optional Extension (A-022.4):
  7. Admin requests approval from rector/timetable admin
  8. Reviewer views simulation evidence
  9. Reviewer approves/rejects with notes
  10. Audit trail captured: approval decision, reviewer, timestamp, notes
  11. Rollback plan generated (how to revert if needed)
  12. STOP: No auto-apply even after approval
  
Level 5 (apply) remains disabled by default, requires explicit user button + confirmation.
```

### Non-Destructive Scheduling Policy

**Invariants (locked for A-022):**
1. ✅ Read-only by default — proposals/simulations → no mutations
2. ✅ No auto-assignment — rooms recommended only
3. ✅ No silent booking override — conflicts must be explicit
4. ✅ No unapproved schedule changes — require approval step
5. ✅ No cross-tenant leakage — proposals isolated by tenant_id
6. ✅ No fake optimization — simulation results reflect ground truth
7. ✅ Auditable reversibility — all approvals logged with timestamp/reviewer
8. ✅ Explicit opt-in for apply — no automatic execution
