## 4. Root Cause Analysis

Root causes were exclusively stale test-contract assumptions introduced by legacy helper patterns:
- Outdated mocked function signatures compared to current service call order.
- Legacy non-numeric IDs incompatible with current persist path (`int(id)`).
- Legacy event expectation (`visitor.arrived`) drifted from A-018 contract (`visitor.checked_in`).
- Visitor fixture rows omitted required schema fields now enforced through tenant entity normalization.
- Update path in visitor service was unmocked in this legacy suite; needed explicit mocked update behavior for in-memory fixture state.

No production defect was identified in visitor/access/security service behavior.
