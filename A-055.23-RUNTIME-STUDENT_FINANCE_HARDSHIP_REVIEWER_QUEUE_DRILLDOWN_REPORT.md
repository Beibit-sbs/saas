# A-055.23 Runtime - Student Finance Hardship Reviewer Queue Drilldown Report

## Scope

Expose a reviewer-visible drilldown list for finance-origin hardship handoffs:

```text
finance-origin hardship readiness records -> reviewer queue -> missing evidence visibility
```

## Result

Added a read-only reviewer queue endpoint:

- Backend route:
  - `GET /api/admin/student-services/hardship/from-finance-handoff/reviewer-queue`
- Backend permission:
  - guarded by `admin.student_services.dashboard.read`
- Backend repository:
  - joins finance-origin hardship records to their linked service request,
  - filters by `metadata_json.source_flow = student_finance_receivables_handoff`,
  - keeps tenant scope.
- Backend response:
  - `student_id`
  - `support_priority`
  - `request_id`
  - `receivables_metadata_id`
  - `readiness_status`
  - `missing_evidence`
  - source metadata and safety flags.
- Frontend API:
  - `getFinanceHardshipReviewerQueue()`
- Frontend dashboard shell:
  - renders `Finance hardship reviewer queue`,
  - shows student, priority, request status, missing evidence, and source receivables metadata id.

## Safety Boundaries

The queue is visibility-only.

It does not approve hardship aid, reject hardship aid, cancel debt, mutate billing balances, execute payments, rank students by hidden score, or call external providers.

Explicitly preserved:

- `noAutomaticAidDecision=true`
- `noBillingBalanceMutation=true`
- `humanReviewRequired=true`
- `fake_metrics=false`
- `provider_live_enabled=false`
- `autonomous_decision_enabled=false`
- `hidden_score_present=false`
