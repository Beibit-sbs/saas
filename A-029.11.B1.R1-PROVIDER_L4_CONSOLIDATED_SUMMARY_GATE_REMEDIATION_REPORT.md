## 6. Root Cause Analysis

| Failure | Test Name | Symptom | Root Cause | Fix Strategy |
|---|---|---|---|---|
| Auth/permission setup | `TestPermissionAndAuthentication::test_route_requires_permission` and related auth-dependent cases | fixture error and downstream unauthorized responses | Test assumed `mocker` fixture is present and used a fake bearer token string instead of platform test JWT pattern | Remove `mocker` reliance; use A-029.8-style JWT headers via `create_access_token`; assert permission dependency from router source |
| 401 unauthorized | multiple response-shape/aggregation/counter tests | endpoint returned 401 for expected authenticated requests | invalid `authenticated_tenant_header` fixture (`Bearer test_jwt_token_with_valid_claims_and_tenant_id_1`) did not satisfy real auth dependency | Replace fixture with deterministic JWT + tenant header helper |
| Path integrity | `TestIntegrity::*` and `TestRouterDetails::test_no_internal_http_forwarding` | `FileNotFoundError` opening `backend/app/modules/provider_readiness/router.py` from `/app/backend` workdir | path assumption prefixed `backend/` while tests already run at `/app/backend`; effective lookup became `/app/backend/backend/...` | Resolve router path with `Path(__file__).resolve().parents[1] / "app/modules/provider_readiness/router.py"` |

## 7. 401 Unauthorized Remediation

Implemented in `backend/tests/test_a02910_provider_readiness_l4_consolidated_summary.py`:
- added `_headers_with_permission()` using `create_access_token(... permissions=["admin.expansion.read"])`;
- added `_headers_without_permission()` for explicit 403 coverage;
- switched authenticated request tests to JWT-based headers;
- replaced fragile `mocker`-based permission check with source assertion for `permission_dependency("admin.expansion.read")`;
- replaced mock-based tenant fail-closed check with invalid `X-Tenant-ID` request (`0`) expecting fail-closed status.

No production auth behavior was weakened or bypassed.

## 8. Path-Integrity FileNotFoundError Remediation

Implemented in `backend/tests/test_a02910_provider_readiness_l4_consolidated_summary.py`:
- introduced `_router_file_path()` using robust path resolution from test file location;
- replaced hard-coded `open("backend/app/modules/provider_readiness/router.py")` with `_router_file_path().open(...)`.

Path-integrity assertions remain intact; only path resolution was corrected for Docker CWD.
