- ✅ GET only (read-only)
- ❌ NO POST, PUT, PATCH, DELETE

- ✅ Tenant derived from authenticated context via `get_current_tenant`
- ✅ Invalid tenant must fail closed (403 or 404)
- ✅ No default tenant fallback
- ✅ All response fields tenant-scoped or tenant-bound

- ✅ Required permission: `admin.expansion.read`
- ✅ Unauthenticated requests: 401
