# AI DevLab Roadmap (2026)

## Level 1: Local Engineering Core
- VS Code tasks and role prompts
- Docker Compose local stack
- CI + security checks

## Level 2: Data-Aware AI
- Safe read-only DB access for AI via MCP
- Schema introspection scripts
- Redaction policy for personal data

## Level 3: One-Command Delivery
- Build + test + package + deploy pipeline
- Environment-specific compose overlays
- Rollback automation and smoke tests

## KPIs
- Lead time from idea to deployed prototype
- Failed deployment rate
- Mean time to recover
- Security findings closure time
