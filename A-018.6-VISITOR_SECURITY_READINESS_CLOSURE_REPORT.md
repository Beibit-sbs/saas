## 3. Lifecycle FSMs

### Visitor Management FSM
```
REQUESTED → APPROVED | REJECTED | EXPIRED | CANCELLED
APPROVED  → CHECKED_IN | EXPIRED | CANCELLED
CHECKED_IN → CHECKED_OUT
```
Terminal states: `CHECKED_OUT`, `EXPIRED`, `REJECTED`, `CANCELLED`

### Security Operations Incident Lifecycle
```
OPEN → ACKNOWLEDGED → INVESTIGATING → RESOLVED | ESCALATED → DISMISSED
```
(state machine enforced in security_operations service)
