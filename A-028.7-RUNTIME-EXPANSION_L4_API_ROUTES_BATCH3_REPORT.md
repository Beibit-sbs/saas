## 8. Tenant Fail-Closed Evidence

- `TrustedTenant = Annotated[dict[str, object], Depends(get_current_tenant)]` — tenant derived from auth context
- Invalid X-Tenant-ID ("0", "-1", "not-an-int") → 400 or 403 (tested in test_a0287)
- Cross-tenant override (token tenant=1, header tenant=2) → 403 (tested in test_a0287)
- No auth header → 401 (tested in test_a0287)
- All 10 A-028.6 service functions accept `tenant_id: int` and are deterministic
- `_build_summary_response()`: `builder(int(tenant["id"]))` — tenant.id passed as int, no override possible
