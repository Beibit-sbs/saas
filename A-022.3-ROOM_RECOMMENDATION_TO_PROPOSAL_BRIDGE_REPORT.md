## 5. Defect Found and Fixed During Validation
Issue encountered:

- bridge evidence attempted to read non-existent fields:
  - selected_candidate.capacity_match.capacity_match_evidence.capacity_ok
  - equipment_ok
  - room_type_ok

Root cause:

- CapacityMatchEvidence in A-020.4 exposes mismatch reasons, not those boolean fields.

Fix applied:

- derive proposal evidence booleans from mismatch_reasons using CapacityMismatchReason values:
  - capacity_ok = no CAPACITY_SHORTAGE/CAPACITY_UNKNOWN
  - equipment_ok = no EQUIPMENT_MISMATCH
  - room_type_ok = no ROOM_TYPE_MISMATCH/ROOM_TYPE_UNKNOWN

Additional hardening:

- fixed brittle test assumption tied to fixed room id; assert now follows selected candidate contract.
