## Scoring Behavior

**Module:** `composite_risk_scorer.compute_composite_risk_score()`

### Factor Weights

| Factor | Weight | Signal | Direction |
|--------|--------|--------|-----------|
| `attendance` | 35% | `attendance_rate` [0-1] | lower → higher risk |
| `grades` | 30% | `grade_pct` [0-100] | lower → higher risk |
| `financial` | 20% | `financial_flag` / `overdue_amount` | flag or debt → higher risk |
| `enrollment` | 15% | `enrollment_status` string | withdrawn/dropped → higher risk |

### Risk Level Thresholds

| Score Range | risk_level | recommended_action |
|-------------|------------|-------------------|
| 0 – 34.9 | `low` | `monitor` |
| 35 – 54.9 | `medium` | `schedule_advising` |
| 55 – 74.9 | `high` | `urgent_advising` |
| ≥ 75 | `critical` | `immediate_intervention` |

### Missing Signal Handling

- Missing optional signal → contributes neutral 50/100 to composite
- Factor reported with `evidence="missing"` in the factors array
- Does NOT crash; all optional parameters default to `None`

## Sweep Job Behavior

**Function:** `early_warning_sweep.run_composite_early_warning_sweep(db_session, actor)`

- Iterates all tenant IDs from `RiskThresholdModel` (existing table, no new table)
- For each tenant, iterates all `StudentProfileModel` rows
- Pulls attendance rate from `LessonAttendanceModel` (30-day window)
- Pulls grade pct from `StudentTopicProgressModel` (quiz_best_score average)
- Calls `compute_composite_risk_score()` — no LLM
- Logs result via `log_admin_action()` (existing audit service)
- Students with `risk_score >= 55` counted in `high_risk_students` counter
- Idempotent: audit service is append-only; no unique constraint to violate
- Per-student exceptions are caught; other students still processed
- Per-tenant exceptions are caught; other tenants still processed

**Scheduler registration** (`scheduler.py`):

```python
self.register_task(
    "composite_early_warning_sweep",
    interval_seconds=24 * 60 * 60,
    task=self._composite_early_warning_sweep,
)
```

Uses **existing** `PlatformWorkerScheduler.register_task()` — no new scheduler created.

**Sweep return shape:**

```json
{
  "tenants_processed": 3,
  "students_processed": 1247,
  "high_risk_students": 89,
  "errors": 0
}
```

## Tenant / Security Proof

1. **Fail-closed on tenant_id:** `compute_composite_risk_score(tenant_id=0, ...)` raises `ValueError("tenant_id is required")` — test `test_zero_tenant_id_raises` confirms.
2. **Fail-closed on student_id:** `compute_composite_risk_score(student_id="", ...)` raises `ValueError("student_id is required")`.
3. **Cross-tenant isolation:** Scorer output `tenant_id` always equals the input `tenant_id`. Score computation uses only the caller-supplied signals — no DB reads in scorer itself. Sweep queries are all filtered by `tenant_id=` explicitly.
4. **Sweep query isolation:** `_sweep_tenant` passes `tenant_id` explicitly to every DB query (`StudentProfileModel.tenant_id == tenant_id`, `LessonAttendanceModel.tenant_id == tenant_id`, etc.).
5. **No new tables:** Zero migrations added.
6. **No new scheduler:** Registered via existing `PlatformWorkerScheduler.register_task()`.
7. **No LLM:** Scoring is purely deterministic arithmetic.
