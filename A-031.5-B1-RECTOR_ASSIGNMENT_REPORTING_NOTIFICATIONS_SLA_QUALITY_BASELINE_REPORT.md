## 4. Runtime Implementation Summary

A-031.5-RUNTIME implemented three capability groups:

**Option A — Notification Outbox Contract**
- New model: `RectorAssignmentOutboxEvent` → `rector_assignment_outbox_events`
- Outbox events queued from 9 lifecycle transitions (create, assign, accept, submit-report, attach-evidence, add-comment, return-for-revision, complete, escalate)
- Statuses: PENDING / READY / CANCELLED only (no live dispatch)
- 10 new `AuditEventType` constants for outbox/SLA/escalation lifecycle
- Helper `_queue_outbox_event()` called from each lifecycle function

**Option B — SLA Policy + Escalation Policy**
- New model: `RectorAssignmentSlaPolicy` → `rector_assignment_sla_policies`
- New model: `RectorAssignmentEscalationPolicy` → `rector_assignment_escalation_policies`
- Both archive-only (is_active=False + archived_at); no hard delete
- `require_manual_confirmation = True` default on escalation policies
- Full CRUD service + repository functions for both

**Option C — Dashboard Analytics Expansion**
- `DashboardSummaryResponse` extended with 8 new optional analytics fields
- `fake_metrics = False` hardcoded; guard assertion in `get_dashboard_summary`
- `data_source = "computed_from_assignments"` hardcoded
- `repo_compute_expanded_dashboard_fields` returns real computed data

## 20. Known Limitations

1. **Outbox = intent queue only**: Outbox events are stored in DB but no consumer/dispatcher reads them. This is by design at this stage — live notification dispatch is explicitly deferred.

2. **SLA not applied to existing assignments**: SLA policy evaluation against live assignment deadlines requires future runtime work (A-031.5-E2E or future wave).

3. **Escalation is manual-confirmation only**: `require_manual_confirmation = True` by default. No automated escalation trigger implemented.

4. **Dashboard fields computed on request**: `repo_compute_expanded_dashboard_fields` runs DB queries synchronously; no caching layer. Performance impact at scale is a known design gap (tracked in A-031.5-SPEC Option D).

5. **A-031.1 continuity count discrepancy**: Runtime report cited 110 (subset run in that session); B1 full suite = 167. Difference is coverage, not regression.

6. **A-030 continuity count discrepancy**: Runtime report cited 362 (subset); B1 full suite = 954. Difference is coverage scope, not regression.
