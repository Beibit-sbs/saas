## Known limitation (honest)

The finance frontend module is a metadata/evidence shell runtime
(`METADATA_EVIDENCE_READINESS_HUMAN_REVIEW_ONLY`) with no live data-fetch
hooks and no `FpaMetadataRecord` frontend type. So this ledger is a
**declarative read-only contract surface**, not a live-rendered record list.
The backend already returns `records[]`; a future node (A-055.31) could type
`records` on the frontend and render the live list once the module gains a
data-fetch path. This is recorded rather than faked.
