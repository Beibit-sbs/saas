# A-055.6 Runtime Student Enrollment Selector Shell Report

Date: 2026-06-18

## Scope

Sixth correction slice after academic program/course linkage:

```text
program/course
  -> student
  -> enrollment
```

The goal of this slice was to reduce raw-id typing for the first cohort enrollment flow and align the frontend create payload with the backend enrollment contract.

## Changed Files

- `frontend/app/(admin)/console/enrollments/page.tsx`
- `frontend/modules/enrollments/api.ts`
- `frontend/modules/enrollments/hooks.ts`
- `frontend/modules/enrollments/types.ts`
- `frontend/__tests__/admin/EnrollmentsPage.test.tsx`

## Result

Enrollments page now:

- loads tenant students for the create drawer
- loads tenant courses for the create drawer
- lets tenant admin choose a student instead of typing a student id
- lets tenant admin choose a course instead of typing a course id
- sends the backend-shaped create payload:

```text
student_profile_id
course_id
term_id
section_id
```

The table and detail drawer now tolerate both older UI-shaped enrollment records and newer backend-shaped records:

- `student_name` or `student_profile_id`
- `section_code` or `section_id`
- `course_name` or `course_id`
- `status` or `enrollment_status`
- string or numeric enrollment ids

This gives the tenant admin a clearer first academic cohort path:

```text
Tenant admin
  -> create student
  -> create/select course
  -> enroll student into course/term/section
```

## Test Coverage Added

`EnrollmentsPage.test.tsx` now verifies that:

- the create drawer exposes a student selector
- the create drawer exposes a course selector
- mocked tenant student/course records appear as selectable options

## Current Limits

Term and section are still raw numeric inputs in this slice.

Reason: this pass did not introduce a tenant-scoped term/section selector contract. The next clean slice should connect scheduling sections to enrollment creation.

Enrollment drop remains a separate contract review item because the frontend still calls the existing drop mutation shape.
