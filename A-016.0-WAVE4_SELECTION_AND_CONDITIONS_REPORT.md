## 3. Wave 4 Top 5 Features

### Feature 1 — Academic Integrity Violation Detection + Response Automation (A-016.1)

**Domain signals:** `academic.integrity.violation_reported`, `academic.integrity.plagiarism_detected`, `campus.integrity.case_opened`

**Brain Core outputs:**
- Classify violation severity (MINOR / MODERATE / SEVERE / CRITICAL)
- Route to appropriate review board or automated warning
- Generate KPI: `integrity_cases_open`, `integrity_violations_by_severity`, `integrity_auto_resolved_rate`

**Automation:** Auto-generate warning notice for MINOR; escalate to review committee for MODERATE+; flag CRITICAL to rector.

---

### Feature 2 — Thesis Submission Pipeline + Supervisor Assignment Automation (A-016.2)

**Domain signals:** `academic.thesis.submitted`, `academic.thesis.supervisor_requested`, `academic.thesis.deadline_missed`

**Brain Core outputs:**
- Match student thesis topic to eligible supervisors (by expertise + availability load)
- Detect stalled submissions (no activity > threshold days)
- Generate KPI: `thesis_submissions_pending`, `supervisor_load_balance_score`, `thesis_deadline_risk_count`

**Automation:** Auto-assign supervisor from ranked pool; trigger reminder workflow on stalled submission; escalate deadline risk to department head.

---

### Feature 3 — Academic Calendar + Deadline Enforcement Brain (A-016.3)

**Domain signals:** `academic.calendar.deadline_approaching`, `academic.enrollment.late_registration`, `campus.schedule.conflict_detected`

**Brain Core outputs:**
- Enforce registration windows; auto-flag late enrollments
- Detect schedule conflicts (room/faculty double-booking)
- Generate KPI: `late_registrations_count`, `schedule_conflicts_detected`, `deadline_compliance_rate`

**Automation:** Block enrollment past hard deadline (configurable override for admin); auto-resolve room conflicts where possible; notify faculty of schedule changes.

---

### Feature 4 — Grade Review + Appeals Workflow Automation (A-016.4)

**Domain signals:** `academic.grade.appeal_submitted`, `academic.grade.review_requested`, `academic.grade.final_posted`

**Brain Core outputs:**
- Route appeal to correct review authority by grade type and department
- Detect anomalous grade distributions (outlier score patterns)
- Generate KPI: `grade_appeals_open`, `appeal_resolution_time_avg`, `anomalous_grade_distributions_flagged`

**Automation:** Auto-acknowledge appeal and set SLA clock; escalate unresolved appeals past SLA; flag grade distribution outliers to academic affairs.

---

### Feature 5 — Academic Performance Monitoring + Early Warning System (A-016.5)

**Domain signals:** `academic.performance.gpa_threshold_breach`, `academic.performance.attendance_risk`, `academic.performance.probation_triggered`

**Brain Core outputs:**
- Classify student at-risk tier (WATCH / AT_RISK / PROBATION / CRITICAL)
- Trigger intervention workflow per tier
- Generate KPI: `students_at_risk_count`, `probation_entries_this_term`, `early_warning_interventions_sent`

**Automation:** Auto-send academic advisor alert for WATCH tier; escalate to department chair for PROBATION; flag CRITICAL to dean with case packet.
