**Executive Summary**

This is a SPEC/PLANNING-only action. A-028.8-RUNTIME will implement the consolidation by:
1. Adding 10 second-wave candidates (A-028.6/A-028.7 batch) to `CONSOLIDATED_MODULE_CATALOG` in router.py

3. Creating targeted tests in a new test file

The endpoint remains read-only, tenant-safe, RBAC/permission-safe, aggregation-only, and evidence-backed. No new endpoint is created. No provider calls, Brain execution, workflow/decision execution, DB mutation, fake KPI, synthetic dashboard, or synthetic scores are involved.
