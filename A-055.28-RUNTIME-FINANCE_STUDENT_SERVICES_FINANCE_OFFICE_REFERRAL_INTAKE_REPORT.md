# A-055.28 Runtime - Finance Vertical Pickup of Student-Services Finance-Office Referral Report

## Scope

Close the bridge back into the finance vertical by exposing, on the finance side, a read-only intake of the finance-office referrals raised by student services:

```text
student-services finance-office referral -> finance read-only referral bridge -> no financial action
```

## Result

Added a finance-side read-only bridge, consistent with the existing finance bridge pattern (`/bridges/*`):

- Backend route:
  - `GET /api/admin/finance-procurement-asset/bridges/student-finance-referrals`
- Backend permission:
  - reuses `finance_procurement_asset.bridges.student_finance.read` (no new permission; permission count stays 50)
- Backend service:
  - `get_bridge_student_finance_referrals` -> `_bridge_response(db, tenant_id, "student_finance_referrals")`
  - reads tenant-scoped `FinanceBridgeRecord` rows of family `student_finance_referrals`
- Frontend:
  - new API client `getFpaBridgeStudentFinanceReferrals`
  - new read-only panel `FpaStudentFinanceReferralIntakePanel` on the `student-finance` route
  - panel declares the endpoint and the expected referral metadata fields (source hardship id, referral target, referral priority, referral reason, recording reviewer) and links back to the student-services referral source.

## Safety Boundaries

The finance-side intake is read-only visibility of referral metadata.

It does not approve aid, reject aid, cancel debt, create tuition charges, mutate billing balances, execute payments, or post to ERP.

Explicitly preserved on the panel:

- `noAutomaticAidDecision=true`
- `noBillingBalanceMutation=true`
- `noPaymentExecution=true`
- `humanReviewRequired=true`

## Current Runtime Meaning

The finance-office referral now has a closed, read-only round trip:

```text
finance receivables handoff -> student-services hardship review ->
finance-office referral -> finance-side read-only referral intake
```

Every hop is metadata-only and human-gated; no automatic financial action
exists on either side of the bridge.
