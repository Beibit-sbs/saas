## 8. Read-Only API Route Standard

**A-028.14 API routes must conform to:**

### Boundaries (Enforced)
- ✅ GET only (no POST/PUT/PATCH/DELETE)
- ✅ Read-only (no state mutation)
- ✅ Tenant-safe (fail-closed on invalid tenant)
- ✅ RBAC-safe (enforce admin.expansion.read)
- ✅ Evidence-backed (wrap L3 readiness + L4 summary)
- ✅ No database mutation
- ✅ No provider call (no requests, httpx, aiohttp)
- ✅ No external submission
- ✅ No Brain execution (no CALL_MODEL, no AUTONOMY)
- ✅ No autonomous execution (no AUTO_* actions)
- ✅ No workflow execution
- ✅ No decision execution
- ✅ No fake KPI or dashboard values
- ✅ No synthetic scores

### Common Route Requirements
- **Route Prefix:** `/api/admin/expansion/l4`
- **HTTP Method:** GET only
- **Permission:** `admin.expansion.read`
- **Tenant Source:** Derived from authenticated context / existing tenant guard
- **Input:** Query parameters optional (filtering, pagination if needed)
- **Response:** 200 OK with L4 visibility summary dict
- **Unauthenticated:** 401 Unauthorized
- **Unauthorized (missing permission):** 403 Forbidden
- **Invalid Tenant:** Fail-closed (400 or 403 or internal error, no exposure)
- **Response Shape:** Preserves all A-028.13 L4 service summary fields

### Response Field Guarantees
All responses must include:
1. tenant_id (request context)
2. module (service module name)
3. uce_id (UCE-###)
4. visibility_level = "L4"
5. source_maturity_level = "L3"
6. visibility_type = "READ_ONLY_SERVICE_SUMMARY"
7. readiness_summary (from L3)
8. risk_summary (from L3)
9. evidence_summary (counted)
10. missing_evidence_summary (from L3)
11. human_review_queue_summary (from L3)
12. allowed_actions (from L3)
13. forbidden_actions (from L3)
14. All 15 safety flags (all True)
15. api_route_deferred_to = "A-028.14" (updated to reflect implementation)
