## 6. SchedulingConflictEvidence Contract

```python
class ConflictType(str, Enum):
    ROOM_TIME_CONFLICT = "room_time_conflict"
    TEACHER_TIME_CONFLICT = "teacher_time_conflict"
    GROUP_TIME_CONFLICT = "group_time_conflict"
    CAPACITY_MISMATCH = "capacity_mismatch"
    COMPUTER_SHORTAGE = "computer_shortage"
    ROOM_TYPE_MISMATCH = "room_type_mismatch"
    EQUIPMENT_MISMATCH = "equipment_mismatch"
    ROOM_UNAVAILABLE = "room_unavailable"
    BOOKING_CONFLICT = "booking_conflict"
    RESTRICTION_MISMATCH = "restriction_mismatch"

class ConflictSeverity(str, Enum):
    LOW = "low"
    MEDIUM = "medium"
    HIGH = "high"
    CRITICAL = "critical"

class SchedulingConflictEvidence(BaseModel):
    tenant_id: int = Field(gt=0)
    conflict_type: ConflictType
    severity: ConflictSeverity
    section_id: Optional[int]
    course_id: Optional[int]
    group_id: Optional[int]
    teacher_id: Optional[str]
    room_id: Optional[str | int]
    day_of_week: Optional[str]
    time_slot: Optional[str | int]
    conflicting_entity_type: Optional[str]
    conflicting_entity_id: Optional[str | int]
    reason: str
    evidence: dict[str, Any]
    source_entity_type: Optional[str]
    source_entity_id: Optional[str | int]
```

**Severity mapping:**
| ConflictType | Severity |
|---|---|
| room_time_conflict | CRITICAL |
| teacher_time_conflict | CRITICAL |
| group_time_conflict | CRITICAL |
| booking_conflict | CRITICAL |
| capacity_mismatch | HIGH |
| room_type_mismatch | HIGH |
| room_unavailable | HIGH |
| computer_shortage | MEDIUM |
| equipment_mismatch | MEDIUM |
| restriction_mismatch | LOW |
