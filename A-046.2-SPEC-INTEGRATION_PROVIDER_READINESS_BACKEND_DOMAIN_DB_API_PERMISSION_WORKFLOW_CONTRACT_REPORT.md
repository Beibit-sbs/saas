## 9 Tenant Contract

Tenant isolation contract:

1. Every entity/table includes tenant_id ownership boundary.
2. All queries are tenant-filtered by default.
3. Cross-tenant reads/writes are forbidden unless explicit governance override path is invoked.
4. Governance override path requires platform_admin + audited reason + immutable audit record.

Cross-tenant restrictions:

- integration_admin, security_admin, auditor, executive_viewer: tenant-local only.
- platform_admin: cross-tenant visibility only through audited governance views.

Audit ownership:

- audit records are immutable and tenant-linked.
- actor_id, role, reason_code, request_context are mandatory on mutating operations.

Visibility rules:

- executive_viewer receives aggregated read-only visibility.
- auditor receives evidence/audit/risk visibility without operational mutation privileges.
- security_admin sees security/compliance/risk lanes only.
