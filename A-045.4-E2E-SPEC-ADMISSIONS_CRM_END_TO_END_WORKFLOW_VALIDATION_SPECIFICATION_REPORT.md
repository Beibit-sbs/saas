## 3. Role Matrix

### 3.1 platform_admin

Allowed actions:

- full navigation across all 14 routes
- create lead/applicant/application
- qualify/convert/submit workflows
- audit page access
- settings/permissions page access

Restricted actions:

- none within Admissions CRM Batch 1 scope

Expected visibility:

- all page families, all dashboard cards, workflow timeline, audit panel, route contract panel

### 3.2 inst_admin

Allowed actions:

- read/write/qualify/convert/submit actions in tenant scope
- navigate overview/leads/applicants/applications/workflows/dashboard

Restricted actions:

- audit route when audit.read is absent
- settings/permissions route when audit.read is absent

Expected visibility:

- CRUD and workflow pages visible
- permission-denied fail-closed state for restricted routes

### 3.3 acad_admin

Allowed actions:

- read and workflow review views
- application review visibility
- dashboard visibility for operational tracking

Restricted actions:

- create/edit actions when write/convert/submit permissions are absent
- audit route when audit.read is absent

Expected visibility:

- read surfaces visible
- action controls hidden/blocked where permission not granted

### 3.4 auditor

Allowed actions:

- read admissions list/detail views
- workflow timeline read visibility
- audit page visibility
- settings/permissions page visibility (audit.read)

Restricted actions:

- all write/qualify/convert/submit actions
- new/create routes blocked where write permission is required

Expected visibility:

- read and audit surfaces only
- consistent fail-closed denied state for modification flows
