**Service-Summary Contract:**

Each selected candidate must implement a read-only service-level L4 visibility summary function with the following structure:

### Common Output Fields (All Candidates)

```python
{
    "tenant_id": <required, fail-closed>,
    "module": <module name>,
    "uce_id": <UCE ID>,
    "visibility_level": "L4",
    "source_maturity_level": "L3",
    "visibility_type": "READ_ONLY_SERVICE_SUMMARY",
    
    # Core Readiness
    "readiness_summary": {
        "status": <operational status>,
        "classification": <deterministic classification>,
        "evidence_level": <completeness>,
    },
    
    # Risk / Evidence
    "risk_summary": {
        "identified_risks": [<list>],
        "mitigation_status": <status>,
    },
    "evidence_summary": {
        "available_evidence": [<items>],
        "completeness": <percentage or boolean>,
    },
    "missing_evidence_summary": {
        "missing_items": [<list>],
        "impact": <severity>,
    },
    
    # Human Review
    "human_review_queue_summary": {
        "queue_status": <status>,
        "pending_actions": [<list>],
    },
    
    # Boundaries
    "allowed_actions": [<list of operations>],
    "forbidden_actions": [<list of prohibitions>],
    
    # Safety Flags (All = True in this batch)
    "tenant_scoped": true,
    "read_only": true,
    "no_mutation": true,
    "no_provider_call": true,
    "no_external_submission": true,
    "no_brain_execution": true,
    "no_autonomous_execution": true,
    "no_workflow_execution": true,
    "no_decision_execution": true,
    "no_fake_kpi": true,
    "no_synthetic_score": true,
    "no_l5_claim": true,
    "no_l6_claim": true,
    
    # Evidence of Preservation
    "l3_contract_preserved": true,
    "api_route_deferred_to": "A-028.14",
}
```

**Tenant Safety Requirements:**
- Mandatory tenant_id input; fail-closed if missing, non-integer, or non-positive
- All returned data must be tenant-scoped; never return cross-tenant data
- Tenant provided in output to enable verification

**Determinism Requirements:**
- Same input (tenant_id + context) produces identical output
- No randomization, no external calls, no timestamp-dependent behavior
- All classifications and status values are deterministic based on L3 business logic

**Read-Only Requirements:**
- Function is read-only; produces no side effects
- Returns only computed/classified state; no mutations
- If later an endpoint is created in A-028.14, endpoint must be GET-only
