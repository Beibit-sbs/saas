## 3. Framework Goals
- Provide reusable, typed, generic admin UI primitives.
- Standardize shell patterns across verticals: actions, filters, states, table shell, permission messaging, audit/evidence/export/kpi cards.
- Avoid backend/permission/business-logic changes.
- Keep all controls capability-aware (disabled when endpoint/workflow is unavailable).
