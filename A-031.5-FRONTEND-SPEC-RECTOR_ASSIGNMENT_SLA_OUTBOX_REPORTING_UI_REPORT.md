## 8. API Client Expansion

### `frontend/modules/rector-assignments/hooks.ts` additions

All new hooks follow existing patterns: React Query + `apiGet`/`apiPost`/`apiPut`/`apiDelete` via BFF. No mock fallback.

#### Outbox hooks

```typescript
// Query keys
OUTBOX: ['rector-assignments:outbox'] as const,
ASSIGNMENT_OUTBOX: (id: number) => ['rector-assignments:outbox', id] as const,

// List all tenant outbox events
function useOutboxEvents(filters?: OutboxEventFilters)
  → apiGet<OutboxEventListResponse>(`${RECTOR_BASE}/outbox`, filters)

// List outbox events for a specific assignment
function useAssignmentOutboxEvents(assignmentId: number)
  → apiGet<RectorAssignmentOutboxEvent[]>(`${RECTOR_BASE}/${assignmentId}/outbox`)

// Mark outbox event ready (mutation — requires outbox.manage)
function useMarkOutboxEventReady(assignmentId: number, eventId: number)
  → apiPost(`${RECTOR_BASE}/${assignmentId}/outbox/${eventId}/ready`, {})
  → invalidates: ASSIGNMENT_OUTBOX(assignmentId), OUTBOX

// Cancel outbox event (mutation — requires outbox.manage)
function useCancelOutboxEvent(assignmentId: number, eventId: number)
  → apiPost(`${RECTOR_BASE}/${assignmentId}/outbox/${eventId}/cancel`, {})
  → invalidates: ASSIGNMENT_OUTBOX(assignmentId), OUTBOX
```

## 18. Anti-Fake UI Requirements

### What frontend implementation MUST NOT do:

- Render hardcoded KPI values in dashboard
- Use mock outbox rows in production-facing pages
- Show "Sent" status if live dispatch did not occur
- Show provider delivery confirmation
- Show a "Send Now" button
- Show a "Dispatch" button
- Show an "Escalate Automatically" option
- Hardcode SLA or dashboard counts
- Bypass the BFF proxy
- Suppress backend errors silently
- Claim production-ready
- Claim L5/L6 promotion
- Suggest email/SMS dispatch is live

### Required visible labels (must appear in outbox/dispatch UI):

| Label | Location |
|---|---|
| "Notification intent queued" | Outbox event status when PENDING |
| "Dispatch disabled" | OutboxRegistry page header notice |
| "Live email/SMS dispatch is not enabled" | AssignmentNotificationTimeline subtext |
| "Provider delivery is out of scope for this release" | OutboxRegistry footer |
| "Manual confirmation required" | EscalationQueuePanel + EscalationPolicyForm |
| "Computed from assignments" | Dashboard footer (existing) |
| "Intent only" | OutboxStatusBadge tooltip for PENDING |

### Dashboard rendering guard (must be preserved and extended):

```typescript
// Existing guard — must remain:
if (data.fake_metrics !== false) {
  return <DataQualityError reason="fake_metrics guard failed" />;
}
if (data.data_source !== "computed_from_assignments") {
  return <DataQualityError reason={`Unexpected data_source: ${data.data_source}`} />;
}
// New — analytics widgets must check for undefined:
// If field is undefined, show widget-level "data unavailable" state
// Never substitute undefined with 0 or placeholder text masquerading as data
```
