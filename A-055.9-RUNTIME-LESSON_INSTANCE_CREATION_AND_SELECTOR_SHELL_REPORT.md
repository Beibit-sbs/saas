# A-055.9 Runtime Lesson Instance Creation And Selector Shell Report

Date: 2026-06-18

## Scope

Ninth correction slice after academic term and course section creation:

```text
course section
  -> create lesson instance
  -> select lesson
  -> mark attendance
```

The goal of this slice was to remove manual lesson id typing from the attendance workflow.

## Existing Backend Contract

Scheduling already exposes:

```text
POST /api/admin/scheduling/sections/{section_id}/lessons
GET  /api/admin/scheduling/sections/{section_id}/lessons
```

No backend endpoint changes were required in this slice.

Frontend:

- `frontend/modules/scheduling/types.ts`

- `frontend/modules/scheduling/hooks.ts`

## Result

Scheduling page now supports:

- selecting a section from loaded tenant sections
- fallback manual section id only when no sections are loaded
- creating a lesson instance under the selected section
- selecting a lesson from the selected section lesson list
- marking attendance against the selected lesson

Lesson creation sends the backend-shaped payload:

```text
scheduled_date
topic_title
notes
metadata_json
```

This closes the first attendance setup chain:

```text
Course
  -> Academic Term
    -> Course Section
      -> Lesson Instance
        -> Attendance
```

## Test Coverage Added

`SchedulingPage.test.tsx` now verifies:

- section selector renders when sections exist
- selecting a section loads the lesson workspace
- lesson selector is populated from section lessons
