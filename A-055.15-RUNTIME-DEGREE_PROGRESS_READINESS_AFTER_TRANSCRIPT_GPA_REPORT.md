# A-055.15 Runtime Degree Progress Readiness After Transcript GPA Report

Date: 2026-06-18

## Scope

Fifteenth correction slice after transcript/GPA:

```text
transcript/GPA
  -> program binding
  -> degree requirements
  -> degree progress evaluation
```

The goal of this slice was to make degree progress reachable from the same tenant admin runtime chain instead of depending on pre-seeded hidden data.

## Result

Backend now exposes tenant degree requirement setup:

```text
GET  /api/admin/degree-progress/requirements
POST /api/admin/degree-progress/requirements
```

Requirement creation validates course existence in the tenant catalog before saving requirement items.

Frontend degree progress page now:

- lets tenant admin select a student instead of typing raw id
- lets tenant admin select a program
- binds the selected student to the selected program as active primary program
- lets tenant admin create a program requirement from selected courses
- loads degree progress and graduation eligibility after setup
- keeps transcript/GPA as the upstream source for credits and completed requirements

Updated runtime branch:

```text
tenant admin
  -> create program/course
  -> create student
  -> bind student to program
  -> create term/section/enrollment
  -> mark attendance
  -> submit grade
  -> verify transcript/GPA
  -> create degree requirement
  -> evaluate degree progress
```

## Current Limits

Deferred:
