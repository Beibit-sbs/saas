# A-044.R1 Admin Console Operability Remediation Report

## Scope
A-044.R1 fixed only the three confirmed blockers from A-044 console audit:
1. Tenant admin local login failed (401).
2. Legacy student services route `/console/student-services-welfare-support` failed operability expectations.
3. Ops summary endpoint path at `/api/bff/v1/platform/ops/summary` returned 404.

No security bypass, no fake KPI synthesis, and no unrelated feature work was introduced.

## Implemented Remediation

### 1) Tenant Admin Local Login Path
- Added explicit, env-controlled tenant-admin bootstrap in [backend/app/bootstrap_admin.py](backend/app/bootstrap_admin.py).
- Added bootstrap env wiring in [infra/docker-compose.yml](infra/docker-compose.yml) and documented defaults in [infra/.env.example](infra/.env.example).
- Bootstrap now supports:
  - `LOCAL_TENANT_ADMIN_BOOTSTRAP_ENABLED`
  - `LOCAL_TENANT_ADMIN_TENANT_ID`
  - `LOCAL_TENANT_ADMIN_LOGINS`
  - `LOCAL_TENANT_ADMIN_PASSWORD`
  - `LOCAL_TENANT_ADMIN_UPDATE_PASSWORD`

### 2) Student Services Route Integrity
- Added compatibility route alias page:
  - [frontend/app/(admin)/console/student-services-welfare-support/page.tsx](frontend/app/(admin)/console/student-services-welfare-support/page.tsx)
- Alias redirects to canonical route `/console/student-services-support`.
- Added targeted regression test:
  - [frontend/__tests__/admin/StudentServicesWelfareSupportAliasRoute.test.tsx](frontend/__tests__/admin/StudentServicesWelfareSupportAliasRoute.test.tsx)

### 3) Ops Summary 404
- Registered platform ops routers in [backend/app/main.py](backend/app/main.py).
- Added bff-compatible ops router in [backend/app/platform/router_ops.py](backend/app/platform/router_ops.py) with path `/api/bff/v1/platform/ops/summary`.
- Preserved canonical `/api/v1/platform/ops/summary`.
- Added explicit anti-fake payload flags in ops response:
  - `data_source: computed_from_runtime_health`
  - `fake_metrics: false`
