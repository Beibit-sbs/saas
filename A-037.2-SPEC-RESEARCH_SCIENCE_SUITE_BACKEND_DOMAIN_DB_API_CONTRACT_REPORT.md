# A-037.2-SPEC - Research / Science Suite Backend Domain / DB / API Contract Report

## 1. Executive Summary

A-037.2-SPEC defines the backend domain, database, API, permissions, schema, repository, service, audit, evidence, dashboard, bridge, migration, and test contract for the future Research / Science Suite backend foundation. This action is spec-only and docs-only. No backend runtime, frontend runtime, migrations, models, schemas, repositories, services, routers, tests, Playwright specs, demo evidence, screenshots, provider integrations, or real research data were added or changed in this action.

The selected backend strategy is one controlled backend module at `backend/app/modules/research_science/` with bounded subdomains, not one package per capability row. The contract uses `rs_` database tables, tenant fail-closed behavior, explicit RBAC permissions, metadata-and-evidence-only safety defaults, append-only audit and status history, read-only-first bridge records, and anti-fake boundaries that forbid autonomous ethics approval, autonomous grant submission, official publication verification, hidden scoring, provider sync, and external live database synchronization.
