## 10. Rollup Logic

All rollups are computed deterministically from aggregated provider summaries:

- **provider_type_rollup**: Counts provider types (all 11 are integrations, all non-live)
- **readiness_status_rollup**: Counts by readiness status from provider summaries
- **blocker_rollup**: Sums blocker counts across all 11 providers
- **missing_evidence_rollup**: Sums missing evidence counts across all 11 providers
- **security_legal_audit_rollback_rollup**: Deterministic hardcoded for NON_LIVE_READINESS boundary (no credentials, no sync, no submission, no mutation)
- **route_coverage**: Documents 11 individual routes + 1 consolidated route; all GET; all admin.expansion.read protected

## 11. Permission / RBAC / Tenant Boundary

**Permission**: `admin.expansion.read` (same as all 11 individual provider L4 routes)

1. JWT authentication (unauthenticated requests return 401)
